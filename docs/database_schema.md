# Database Schema Reference

This reference guide documents all tables, columns, indexes, and calculated views in the `kb-web` SQLite database structure, which serves as the baseline for the PostgreSQL migration.

---

## 1. Tables

### `fetched_pages`
Stores the metadata and contents of all fetched web pages.
- `url` (TEXT, Primary Key): URL of the page.
- `title` (TEXT): Title of the page.
- `html_content` (TEXT): Original raw HTML content.
- `md_content` (TEXT): Cleaned markdown content.
- `md_content_hash` (TEXT): Hash of the markdown content for duplicate detection.
- `html_content_hash` (TEXT): Hash of the raw HTML content.
- `fetched_at` (TEXT): Timestamp when the page was crawled/imported.
- `description` (TEXT): Wiki description generated by Ollama.
- `keywords` (TEXT): Keywords extracted by Ollama.
- `collection_id` (INTEGER, Nullable): Associated collection ID.
- `exclude_from_general` (INTEGER, Default 0): Boolean toggle.

### `page_versions`
Historical database archives of pages whose contents have changed.
- `id` (INTEGER, Primary Key AUTOINCREMENT): Version identifier.
- `url` (TEXT): Source URL.
- `title` (TEXT): Historical title.
- `html_content` (TEXT): Historical raw HTML.
- `md_content` (TEXT): Historical markdown.
- `md_content_hash` (TEXT): Historical markdown hash.
- `html_content_hash` (TEXT): Historical HTML hash.
- `fetched_at` (TEXT): Historical fetched timestamp.
- `description` (TEXT): Historical wiki description.
- `keywords` (TEXT): Historical keywords.
- `tags` (TEXT): Historical tags.

### `site_wikis`
Domain-specific wiki content.
- `site` (TEXT, Primary Key): Domain netloc.
- `wiki_content` (TEXT): Combined domain wiki text.
- `updated_at` (TEXT): Last updated timestamp.

### `youtube_videos`
Video attributes mapped to fetched pages.
- `url` (TEXT, Primary Key REFERENCES fetched_pages): Page URL.
- `video_id` (TEXT): YouTube Video ID.
- `creator` (TEXT): Channel / Creator name.
- `channel_id` (TEXT): Creator channel ID.
- `duration` (INTEGER): Duration in seconds.
- `view_count` (INTEGER): Total views count.
- `thumbnail_url` (TEXT): Video thumbnail link.
- `local_path` (TEXT): Storage path of downloaded mp4.
- `updated_at` (TEXT): Last updated timestamp.

### `collections`
Groups related pages and notes.
- `id` (INTEGER, Primary Key AUTOINCREMENT): ID.
- `title` (TEXT): Title of the collection.
- `visibility` (TEXT): Collection visibility settings.
- `rag_system_prompt` (TEXT): System prompt settings for chat RAG.
- `taxonomy_system_prompt` (TEXT): Taxonomy generation prompt.
- `general_system_context` (TEXT): Context parameters.
- `created_at` (TEXT): Creation timestamp.

### `collection_items`
Cross-reference mapping items into collections.
- `id` (INTEGER, Primary Key AUTOINCREMENT): Item ID.
- `collection_id` (INTEGER REFERENCES collections): Parent collection.
- `source_type` (TEXT): e.g., 'page', 'note', 'link'.
- `source_id` (TEXT): URL or identifier.
- `item_note` (TEXT): Custom annotation.
- `taxonomy_path` (TEXT): Category hierarchy location.
- `item_order` (INTEGER): Ordering order.
- `added_at` (TEXT): Entry timestamp.

### `collection_notes`
Collection-specific textual notes.
- `id` (INTEGER, Primary Key AUTOINCREMENT): ID.
- `collection_id` (INTEGER REFERENCES collections): Parent collection.
- `title` (TEXT): Title.
- `content` (TEXT): Content body.
- `taxonomy_path` (TEXT): Category hierarchy.
- `created_at` (TEXT): Creation timestamp.
- `updated_at` (TEXT): Last updated.

### `links`
Catalog of saved regular webpage links.
- `id` (INTEGER, Primary Key AUTOINCREMENT): ID.
- `url` (TEXT, Unique): URL.
- `title` (TEXT): Title.
- `description` (TEXT): Description.
- `click_count` (INTEGER): Total usage redirections count.
- `created_at` (TEXT): Creation date.
- `last_clicked_at` (TEXT): Last usage date.

### `article_embeddings` / `title_embeddings` / `video_embeddings`
Gemma embedding vectors stored as serialized JSON strings in SQLite.
- `url` (TEXT, Primary Key REFERENCES fetched_pages): Target URL.
- `embedding` (TEXT): Serialized vector list.
- `updated_at` (TEXT): Generation timestamp.

### `chunk_embeddings`
Granular document chunk embeddings for RAG searches.
- `id` (INTEGER, Primary Key AUTOINCREMENT): ID.
- `source_type` (TEXT): e.g. 'page'.
- `source_id` (TEXT): URL.
- `source_title` (TEXT): Page title.
- `chunk_number` (INTEGER): Order index.
- `chunk_content` (TEXT): Chunk content.
- `chunk_vector` (TEXT): Serialized vector list.
- `created_at` (TEXT): Creation timestamp.

### `ollama_logs`
LLM request and response logs.
- `id` (INTEGER, Primary Key AUTOINCREMENT): ID.
- `timestamp` (TEXT): Request timestamp.
- `model` (TEXT): Ollama model name.
- `prompt_type` (TEXT): e.g., 'wiki', 'tags'.
- `messages` (TEXT): Input prompt.
- `options` (TEXT): Generation parameters.
- `response` (TEXT): Output response.
- `duration` (FLOAT): Latency in seconds.
- `status` (TEXT): e.g., 'success', 'failed'.

### `system_logs`
Local runtime event logs.
- `id` (INTEGER, Primary Key AUTOINCREMENT): Log identifier.
- `timestamp` (TEXT): Timestamp.
- `level` (TEXT): log level (INFO, ERROR, etc.).
- `module` (TEXT): Code module name.
- `message` (TEXT): Log message text.
- `traceback` (TEXT): Stack trace for exceptions.

### `cli_api_keys`
API tokens authorized for CLI tools.
- `key` (TEXT, Primary Key): Token.
- `name` (TEXT): Name of client key owner.
- `created_at` (TEXT): Creation date.

### `registered_clients`
Computers registered using the CLI setup.
- `computer_name` (TEXT, Primary Key): Hostname.
- `api_key` (TEXT): Key mapped.
- `registered_at` (TEXT): Timestamp.
- `status` (TEXT): Status tag.

---

## 2. Calculated SQL Views

- `vault_master`: Aggregates obsidian vault files paths, hashes, and text descriptions.
- `repo_master`: Aggregates directory repository files paths, hashes, and text descriptions.
- `valid_repo_files`: Filters repo master files bounded by size limits.
- `valid_vault_files`: Filters vault master files bounded by size limits.
- `root_items`: Cross-references directories scanner data.
